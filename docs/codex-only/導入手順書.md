# Codex 節約設定 導入手順書

この手順で、Codex の使用量（トークン）を減らす設定を入れる。所要時間：約10分。

> ※ Codex は更新が速く、コマンド名や設定項目が変わることがあります。
> 　 手順どおりに動かない箇所は、公式ドキュメント（OpenAI Codex / GitHub の openai/codex）で確認してください。

---

## STEP 0. 前提：Codex が動くこと
ターミナルで `codex` が起動し、ログインできていれば STEP 1 へ。
まだなら：
```
npm install -g @openai/codex
codex          # 起動後、ChatGPT アカウントでサインイン
```
（Node.js が必要。Windows でうまく動かない場合は WSL 上で実行）

---

## STEP 1. 全プロジェクト共通の節約ルールを入れる
Codex は `~/.codex/AGENTS.md` を全プロジェクトで読む。ここに AGENTS.md を置く。

**Mac / Linux / WSL**
```
mkdir -p ~/.codex
cp AGENTS.md ~/.codex/AGENTS.md
```
**Windows（PowerShell）**
```
mkdir $HOME\.codex -Force
copy AGENTS.md $HOME\.codex\AGENTS.md
```
※ すでに `~/.codex/AGENTS.md` がある場合は、上書きせず末尾に中身を追記する。

---

## STEP 2. 推論の強さの既定値を下げる
既定を「中」にしておき、難しい作業のときだけ上げる（毎回最大で動かすのが一番の無駄）。

`~/.codex/config.toml` を開き（なければ作成）、次の1行を追加：
```
model_reasoning_effort = "medium"
```
- 定型作業が中心なら `"low"` でもよい
- 設計・原因不明のバグのときだけ、会話中に `/model` で強い設定に切り替える
- モデル名（`model = ...`）は変わりやすいので、特に理由がなければ書かず既定のままにする

---

## STEP 3. プロジェクトごとのルール（必要な場合のみ）
特定のプロジェクトだけ追加ルールがある場合は、そのプロジェクト直下に `AGENTS.md` を置く。
```
my-project/
├─ AGENTS.md   ← プロジェクト固有のルールだけ書く（共通ルールは STEP 1 にあるので重複させない）
└─ src/
```
**短く保つこと。** AGENTS.md は毎回読み込まれるため、長いほど毎回のコストが増える。

---

## STEP 4. 反映されたか確認
1. 任意のプロジェクトで `codex` を起動し直す
2. 次を入力：
   ```
   読み込んでいる AGENTS.md の節約ルールを3行で要約して
   ```
3. ルールの内容が返れば OK
4. `/status` で現在のモデル・設定を確認（推論の強さが反映されているか）

---

## STEP 5. 使い方の習慣（設定だけでは節約にならない）
| 習慣 | 理由 |
|---|---|
| タスクが変わったら新しい会話（`/new` か再起動） | 長い会話は1回ごとの消費が増える |
| 会話が長くなったら `/compact` | 履歴を要約して軽くする |
| 依頼にファイル名を書く | Codex にファイルを探させない |
| 1回の依頼は1機能＋完了条件 | やり直しを減らす |
| エラーは該当の数行だけ貼る | 入力量を減らす |

依頼テンプレ（コピーして使う）：
```
対象: src/〇〇.ts の △△
やること: 〜〜（1つだけ）
完了条件: npm test が通ること
触らないもの: それ以外のファイル
```

---

## 元に戻す方法
- ルールを外す：`~/.codex/AGENTS.md` を削除（またはリネーム）
- 推論設定を戻す：`~/.codex/config.toml` から追加した1行を削除
