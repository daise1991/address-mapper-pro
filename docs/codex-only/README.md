# Codex だけで節約して使うためのガイド

## 1. 設置
`導入手順書.md` の手順どおりに入れる。

## 2. 頼み方（ここが一番効く）
- **ファイル名を指定する**：「`src/geocode.ts` の normalize 関数に全角→半角変換を追加」
  （Codex に探させると読み込みが増える）
- **1回の依頼は1機能**。完了したら次へ
- **完了条件を書く**：「`npm test` が通ること」
- エラーは全文でなく、該当部分だけ貼る

## 3. 会話の管理
- タスクが変わったら新しい会話にする（`/new`）。長い会話は1回ごとの消費が増える
- 長くなったが続けたい場合は `/compact` で要約する

## 4. モデル・推論の強さ
- 定型作業（名前変更・テスト追加・小修正）は軽い設定、設計やバグ調査は強い設定、と使い分ける
- `/model` で切り替えられる。既定値は `~/.codex/config.toml` の `model` / `model_reasoning_effort` で設定できる

## 5. やらせない方がいいこと
- 「全体を見て改善して」のような範囲のない依頼
- API キー発行・課金設定・画面の目視確認（人がやる方が速くて安い）
