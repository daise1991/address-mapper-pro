# 手順書：Codex 節約セットの導入と使い方

所要時間：導入 約10分。
※ インストールコマンドや画面上のコマンド名は Codex の更新で変わることがあります。
　 動かない場合は公式（OpenAI Codex のドキュメント / GitHub の openai/codex）を確認してください。

---

## STEP 1. Codex を使える状態にする（初回のみ）
1. Node.js（LTS版）を入れる：https://nodejs.org
2. ターミナルで Codex をインストール
   ```
   npm install -g @openai/codex
   ```
3. 起動してログイン（ChatGPT アカウントでサインイン）
   ```
   codex
   ```
4. Windows の場合：うまく動かなければ WSL（Ubuntu）上で実行する

## STEP 2. 節約ファイルを置く
1. 受け取った `AGENTS.md` を、作業するプロジェクトのフォルダ直下にコピー
   ```
   my-project/
   ├─ AGENTS.md   ← ここ
   ├─ src/
   └─ ...
   ```
2. すでに `AGENTS.md` がある場合は、上書きせず中身を末尾に追記する
3. （任意）全プロジェクト共通にしたい場合は `~/.codex/AGENTS.md` にも置く

## STEP 3. 動作確認
1. プロジェクトのフォルダで `codex` を起動
2. 次のように聞く
   ```
   AGENTS.md の節約ルールを3行で要約して
   ```
3. ルールの内容が返ってくれば読み込み成功

## STEP 4. 毎回の使い方（基本の型）
依頼は次の4点を入れる。コピーして使う：
```
対象: src/〇〇.ts の △△ 関数
やること: 〜〜を追加（1機能だけ）
完了条件: npm test が通ること
触らないもの: それ以外のファイル
```
- 1つ終わったら次の依頼へ。まとめて頼まない
- エラーは全文でなく、該当の数行だけ貼る

## STEP 5. 会話の区切り方
| 状況 | 操作 |
|---|---|
| 別のタスクに移る | 新しい会話を始める（`/new`、または codex を起動し直す） |
| 同じタスクで会話が長くなった | `/compact` で要約して続ける |
| 定型作業（名前変更・小修正・テスト追加） | `/model` で軽い設定に切り替え |
| 設計・原因不明のバグ | 強い設定に戻す |

## STEP 6. Codex に頼まず自分でやること
- API キーの発行・課金設定・外部サービスの登録
- 画面の見た目の確認、実機での動作確認
- 仕様や優先順位の決定
→ Codex が「人に任せる」と TODO を返したら、ここに該当します。
