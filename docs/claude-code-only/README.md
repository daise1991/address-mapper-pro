# Claude Code だけで節約して使うためのガイド

## 1. 設置
`導入手順書.md` の手順どおりに入れる。

## 2. 頼み方（ここが一番効く）
- **ファイル名を指定する**：「`@src/geocode.ts` の normalize 関数に全角→半角変換を追加」
- **1回の依頼は1機能**。完了したら次へ
- **完了条件を書く**：「`npm test` が通ること」
- エラーは全文でなく、該当部分だけ貼る

## 3. 会話の管理
- タスクが変わったら `/clear`。長い会話は1回ごとの消費が増える
- 続けたいが長くなった場合は `/compact`
- `/context` で容量の使われ方を確認できる

## 4. モデルの使い分け
- 定型作業は軽いモデル、設計やバグ調査は強いモデル。`/model` で切り替え

## 5. やらせない方がいいこと
- 「全体を見て改善して」のような範囲のない依頼
- API キー発行・課金設定・画面の目視確認（人がやる方が速くて安い）
