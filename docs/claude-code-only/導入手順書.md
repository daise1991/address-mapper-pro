# Claude Code 節約設定 導入手順書

この手順で、Claude Code の使用量（トークン）を減らす設定を入れる。所要時間：約10分。

> ※ Claude Code は更新が速く、コマンド名や設定項目が変わることがあります。
> 　 手順どおりに動かない箇所は公式ドキュメント（https://code.claude.com/docs）で確認してください。

---

## STEP 0. 前提：Claude Code が動くこと
ターミナルで `claude` が起動し、ログインできていれば STEP 1 へ。
まだなら：
```
npm install -g @anthropic-ai/claude-code
claude          # 起動後、Claude アカウントでログイン
```

---

## STEP 1. 全プロジェクト共通の節約ルールを入れる
Claude Code は `~/.claude/CLAUDE.md` を全プロジェクトで読む。ここに CLAUDE.md を置く。

**Mac / Linux / WSL**
```
mkdir -p ~/.claude
cp CLAUDE.md ~/.claude/CLAUDE.md
```
**Windows（PowerShell）**
```
mkdir $HOME\.claude -Force
copy CLAUDE.md $HOME\.claude\CLAUDE.md
```
※ すでに `~/.claude/CLAUDE.md` がある場合は、上書きせず末尾に中身を追記する。

---

## STEP 2. 読まなくていいファイルを禁止する（強制力あり）
CLAUDE.md のルールは「お願い」だが、ここは**設定で確実に止める**。
プロジェクト直下の `.claude/settings.json` を作成（既にあれば `permissions.deny` に追記）：
```json
{
  "permissions": {
    "deny": [
      "Read(./node_modules/**)",
      "Read(./dist/**)",
      "Read(./build/**)",
      "Read(./package-lock.json)",
      "Read(./.env)",
      "Read(./.env.*)"
    ]
  }
}
```
- プロジェクトに合わせて、大きなデータフォルダ等を追加する
- `.env` を入れておくと、APIキーの読み込み防止にもなる

---

## STEP 3. モデルを作業で使い分ける
一番高いモデルで全部やるのが最大の無駄。会話中に `/model` で切り替える。

| 作業 | モデル | `/model` で選ぶ名前 |
|---|---|---|
| ファイル探し・軽い質問・要約 | Haiku 5.5 | `haiku` |
| 通常の実装・テスト追加・小修正（基本はこれ） | Sonnet 5.5 | `sonnet` |
| 設計・原因不明のバグ・大きなリファクタ | Opus 5.5 | `opus` |

- 既定は Sonnet にしておき、必要なときだけ Opus に上げる
- 既定は `~/.claude/settings.json` に `"model": "sonnet"` と書いて固定できる
- モデル名は更新で変わるので、`/model` の一覧に出る名前を優先する

---

## STEP 4. プロジェクトごとのルール（必要な場合のみ）
特定のプロジェクトだけ追加ルールがある場合は、そのプロジェクト直下に `CLAUDE.md` を置く。
```
my-project/
├─ CLAUDE.md   ← プロジェクト固有のルールだけ（共通ルールは STEP 1 にあるので重複させない）
├─ .claude/settings.json   ← STEP 2
└─ src/
```
- 起動して `/init` を使うと雛形を自動生成できるが、**生成後に短く削る**こと（長いほど毎回のコスト増）

---

## STEP 5. 反映されたか確認
1. 任意のプロジェクトで `claude` を起動し直す
2. `/memory` で読み込まれている CLAUDE.md を確認
3. `/context` で、会話の容量のうち何がどれだけ使っているかを確認
4. 「node_modules の中を読んで」と頼み、拒否されれば STEP 2 が効いている

---

## STEP 6. 使い方の習慣（設定だけでは節約にならない）
| 習慣 | 理由 |
|---|---|
| タスクが変わったら `/clear` | 長い会話は1回ごとの消費が増える |
| 同じタスクで長くなったら `/compact` | 履歴を要約して軽くする |
| 大きな作業は先にプランモード（Shift+Tab）で方針確認 | やり直しを減らす |
| 依頼にファイル名を書く（`@src/foo.ts` で指定可） | Claude にファイルを探させない |
| 1回の依頼は1機能＋完了条件 | やり直しを減らす |
| エラーは該当の数行だけ貼る | 入力量を減らす |

依頼テンプレ（コピーして使う）：
```
対象: @src/〇〇.ts の △△
やること: 〜〜（1つだけ）
完了条件: npm test が通ること
触らないもの: それ以外のファイル
```

---

## 元に戻す方法
- ルールを外す：`~/.claude/CLAUDE.md` を削除（またはリネーム）
- 読み込み禁止を外す：`.claude/settings.json` から該当行を削除
