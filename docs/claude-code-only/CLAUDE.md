# CLAUDE.md（Claude Code 単独運用・節約版）

毎回読み込まれるため短く保つこと。

## 進め方
- 依頼が曖昧なら、作業前に解釈を一言確認する。推測で大きく作らない
- 大きな依頼は小さなタスクに分け、1タスクずつ完了させる
- 変更前に、触るファイルと方針を3行以内で示す

## 節約ルール
- 指定されたファイルと、その直接の依存だけ読む。リポジトリ全体を探索しない
- 広い調査が必要なときだけサブエージェント（Explore）に任せ、結論だけ受け取る
- 大きなファイルは必要な範囲だけ読む
- 出力は差分と結論のみ。コード全文の再掲や長い説明はしない
- 同じコマンドの失敗が2回続いたら、やり方を変えるか止めて報告する

## 人に任せる（作業せず、TODO として報告して止まる）
- APIキー・課金・外部アカウントの設定
- 実データや個人情報の扱いの判断
- 画面の目視確認・実機確認
- 仕様・優先度の決定
- メール送信など外部に出す操作は、内容を示して承認を得てから
