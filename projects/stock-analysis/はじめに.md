# はじめに（かんたん手順）

このアプリは、毎営業日の夕方に次のことを自動で行います。

- 60銘柄を「成長期待・買い・売り」の3つの点数で採点する
- 「買い候補」と「売りを検討する保有株」をスマホとPCに通知する

**注文は自動では出しません。** 内容を見て、ご自分で SBI証券から注文してください。

---

## 1. 最初に1回だけやること（30分ほど）

### ① 必要なソフトを入れる
1. スタートボタンを右クリックし、「ターミナル」を開きます。
2. 次の2行を1行ずつ貼り付けて Enter を押します。
   ```
   winget install Python.Python.3.12
   winget install OpenJS.NodeJS.LTS
   ```
3. 終わったら、PCを再起動します。

### ② GitHub からファイルを取ってくる
1. ターミナルで次を実行します。
   ```
   cd C:\Augma
   git clone https://github.com/daise1991/address-mapper-pro.git
   ```
   - 非公開リポジトリなので、ブラウザで GitHub へのログインを求められたらログインしてください。
2. 次の場所に `scripts` フォルダがあれば成功です。
   `C:\Augma\address-mapper-pro\projects\stock-analysis\scripts`

### ③ J-Quants に登録する（株価データの取得元）
1. https://jpx-jquants.com/ で登録し、**Light プラン（月1,650円）** を申し込みます。
   - 無料プランだと株価が12週間遅れるため、毎日の分析には使えません。
2. ログイン後、「設定 → APIキー」を開き、キーをコピーします。

### ④ セットアップを実行する
1. `scripts` フォルダの **`setup.bat`** をダブルクリックします。
2. 途中で APIキーを聞かれたら、③でコピーしたキーを貼り付けて Enter を押します。
   - キーがまだ無ければ、空のまま Enter を押してください。お試し用の**デモデータ**（架空の数字）で起動します。
3. 最後に表示される「アクセス用トークン」は、スマホで使うときに必要になるのでメモしておきます。

### ⑤ 毎日自動で動くようにする
1. **`register-task.bat`** をダブルクリックします。これで、PCにサインインするたびに自動で起動します。
2. 15:30〜18:30 にPCがスリープしていると分析されません。
   「設定 → システム → 電源」で、スリープを「なし」にしてください。

## 2. 毎日の使い方

1. **`start.bat`** をダブルクリックすると、ブラウザで画面が開きます。
2. 18時ごろ、通知が届いたら次の順に見ます。

| 画面 | 見るところ |
|---|---|
| **売買候補** | 「翌営業日 S株 注文案」に、何株買うかの目安が出ます |
| **ランキング** | 全銘柄の点数の一覧です。銘柄をクリックすると詳細が出ます |
| **保有・資金** | 持っている株と、買付余力（SBI証券の画面の数字）を入力します |

**夜（13:30〜24:00）に S株を注文すると、翌営業日の朝の寄付（前場始値）で買えます。**

### 点数の見方
- **成長期待**（高いほど良い）: 会社が伸びそうか
- **買い**（高いほど割安）: 今の株価が将来の価値に比べて安いか
- **売り**（高いほど危険・割高）: 売りを考えるべきか
- **「未算定」**: 赤字などで計算できないという意味です。0点ではありません。
- **「自」マーク**: 会社予想から機械的に出した仮の点数です。

### 判定の意味
- **積極購入候補・通常購入候補**: 買いを検討してよい銘柄です。
- **割安待ち**: 良い会社だが、今は高い銘柄です。値下がりを待ちます。
- **利益確定候補**: 会社は好調だが、株価が上がりすぎている銘柄です。
- **損切り・撤退候補**: 業績悪化など、買った理由が崩れた銘柄です。

---

## 3. スマホ（iPhone）で通知を受け取るには

PCの外から見られるようにする設定が必要で、少し難しい作業です。必要になったら Claude に「iPhone 通知を設定したい」と頼んでください。

---

## 4. 困ったとき

- **画面が開かない**: `stop.bat` を押してから、もう一度 `start.bat` を押します。
- **赤いお知らせ（データ遅延）が出る**: 株価データの配信が遅れています。そのまま待てば自動で取り直します。
- **それでも直らない**: `backend\data\app.log` の中身を Claude に貼り付けて相談してください。
