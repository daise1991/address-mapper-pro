現在の方式は `2026.10-v4` です。改善版を `2026.10-v5` として**別バージョンで追加**し、過去の点数と旧方式は削除しません。

## 1. 現行仕様と改善案の差分

### A. 成長期待点（7項目・配点は維持）

| 論点 | 現行（v4） | 改善案（v5） |
|---|---|---|
| 評価する期間 | 売上・営業利益の伸びは「前期→今期」と「今期→会社予想」の2点だけ | **過去3〜5年の年平均成長率**（J-Quants Light は5年分）＋**2029年までの予測成長率**（標準シナリオ）。配分は過去40%・予測60% |
| 点数変換 | 区分線形の表はあるが文書化されていない | すべての表を本書の付表で数値として定義し、テストで固定する（下記） |
| 欠損項目の扱い | 欠損を**除外して残りで100点に換算**（データが少ないほど高得点になり得る） | **欠損は0点として加算し、換算しない**（点数＝Σ配点×項目点÷100）。充足率を併記する |
| 正式採点の条件 | 充足率50%以上 | **充足率80%以上で正式**、50〜80%は「暫定評価」、50%未満は「未算定」 |
| 定性2項目（市場拡大・競争優位） | 利用者の手入力のみ（現状すべて未入力） | 調査時に根拠付きで作成し、v5 専用の表に保存する。検証済みの項目だけ正式点数に使う（2026-10-10 改定: [qualitative-v2-spec.md](qualitative-v2-spec.md)） |

**点数変換表（v5案）**

| 項目 | 指標 | 点数変換（指標の値→点数、間は直線補間） |
|---|---|---|
| 売上成長 | 過去3〜5年の年平均成長率 ×0.4 ＋ 2029年までの予測年平均成長率 ×0.6 | -10%→0、0%→30、5%→50、10%→70、15%→85、25%以上→100 |
| 営業利益成長 | 同上（営業利益。赤字→黒字は「改善」として70点を上限） | -20%→0、0%→30、5%→45、10%→65、20%→85、30%以上→100 |
| 市場拡大 | 調査・手入力の定性評価（0〜100、根拠必須） | そのまま |
| 競争優位性 | 同上 | そのまま |
| 収益性 | 営業利益率の過去3〜5年平均（50%）、ROEの過去3〜5年平均（50%） | 営業利益率: 0%→20、5%→45、10%→65、20%→85、30%→100 ／ ROE: 0%→20、8%→55、15%→80、25%→100 |

| 2029年の成長可能性 | 標準シナリオの2029年EPS÷直近実績EPSの年率（60%）、定性の成長見通し（40%） | 年率 -10%→0、0%→30、8%→55、15%→75、25%以上→95 |

### B. 買い点数（式・係数200は維持、係数150も保存を継続）

| 論点 | 現行（v4） | 改善案（v5） |
|---|---|---|
| 3シナリオ | 調査前提のある銘柄だけ（現在10銘柄）。点数は標準シナリオで計算 | 同じ。全60銘柄に展開する |
| 弱気シナリオの下落リスク | 銘柄詳細に弱気の理論価値を表示するだけ | 「**弱気時の下落率**＝弱気理論価値÷終値−1」をランキングと注文案に表示する |
| 予測配当 | **反映していない** | 目標期末までに受け取る予想配当の現在価値を V に加算する。配当は「会社予想配当」と「標準EPS×過去3年平均の配当性向」の低い方。EPS×PER の将来株価は配当落ち後の価格とみなし、配当の二重計上を防ぐ |
| 景気循環株 | 正常化EPSを基準に、標準EPSが正常化の1.5倍を超えると警告 | 同じ。加えて「正常化EPS×想定PER」の理論価値も併記する |
| 赤字企業 | PERは適用せず「未算定」 | 2029年に黒字化の根拠があれば、その年のEPSでPERを適用する。黒字化の根拠がなく売上予測がある場合は「2029年売上×想定PSR（成長性に応じ1〜6倍）」で評価する。根拠がなければ「未算定」 |
| 未算定と0点 | 区別済み（NULL） | 維持 |

### C. 売り点数（7項目・配点は維持）

| 論点 | 現行（v4） | 改善案（v5） |
|---|---|---|
| 点数変換 | 表はあるが文書化されていない | 付表で定義して固定する（下記） |
| 重大リスク | 下方修正・増資が80以上だと、売り点数を「その8割」まで**引き上げ**ていた（川崎重工の80点はこれ） | **売り点数は7項目の加重合計だけにする**（引き上げを廃止）。重大リスクは**別の警告**として表示し、売り点数が低くても「売却・撤退の再評価対象」にして、購入候補からは外す |
| RSI | 株価過熱＝max(RSI, 25日線乖離, 200日線乖離) で、RSIだけでも最大10点になる | 過熱はRSIと移動平均乖離の**平均**にする。RSI単独では過熱を最大40点（＝売り点数で最大4点）に抑え、中長期の判断材料にしない |
| 欠損項目 | 除外して換算 | 0点として加算し、充足率を表示する（充足率80%未満は暫定） |
| 株式分割 | v4で修正済み（調整係数で補正、整数倍の急増は除外） | 維持し、回帰テストを追加する |

**重大リスク警告の条件（v5案）**: 次のどれかに該当したら警告を出します。
- 営業利益予想の15%以上の下方修正
- 営業CF赤字かつ自己資本比率20%未満
- 1年で10%以上の株数増加（分割は除く）
- 増資・MSワラントの開示
- 債務超過

**売り点数の変換表（v5案）**

| 項目 | 点数変換 |
|---|---|
| 割高度（25） | 株価÷標準理論価値: 0.8→0、1.0→25、1.2→60、1.5→90、2.0→100 |
| 業績鈍化（15） | 予想営業利益の伸び: -30%→100、-10%→75、0%→55、5%→35、15%→10、30%→0。過去3〜5年の年平均成長率より15%以上低ければ＋15 |
| 下方修正リスク（15） | 120日以内の下方修正1件につき40点。四半期進捗の遅れ: -25%→90、-10%→55、0%→20。上方修正があれば−20 |
| 財務悪化（15） | max(営業CF赤字→70、自己資本比率 10%→80・20%→50・35%→15・50%→0、有利子負債の急増 総資産比5%→25・15%→60) |
| 増資・希薄化（10） | 分割補正後の株数増加率: 0%→0、3%→50、10%→100。増資の開示があれば70以上 |
| 株価過熱（10） | (RSI点＋乖離点)÷2。RSI: 60→0、70→40、80→80 ／ 乖離: 25日線5%→0、15%→50、30%→100（200日線60%→60） |
| 見通し悪化（10） | 成長期待点の90日前からの低下: 5点→30、10点→60、20点→100。定性の成長見通しが60未満なら補正 |

### D. 予測信頼度 A〜D（新規）

現在は、調査担当が付けた「高・中・低」だけです。v5 では次の5要素を点数化して判定します。

| 要素 | 配点 | 内容 |
|---|---|---|
| データ充足率 | 30 | 成長・売りの両方の充足率の低い方 |
| 情報源 | 25 | J-Quants・EDINET などの公式データとの照合で一致している割合（検索ベースだけなら減点） |
| 更新日 | 15 | 前提の最終確認からの日数（90日以内で満点、365日で0） |
| 予測幅 | 15 | (強気−弱気)÷標準の大きさ（幅が狭いほど高い） |
| 過去の予測誤差 | 15 | 過去の会社予想・自社推計と実績の差（データが無い間は7点で固定） |

- **判定**: 85点以上がA、70以上がB、50以上がC、50未満がD です。
- **強制D**: 必須データ（終値・会社予想・3シナリオ）の欠落や、公式データとの10%超の矛盾がある場合は、点数に関係なくDにします。
- **注文候補**: A・Bだけを正式な候補に載せます。C・Dは参考ランキングにだけ表示します。

| 論点 | 現行（v4） | 改善案（v5） |

## 3. 変更前後の点数への影響（予測）

本物のデータでの影響は、PCで**v4とv5を並行採点（影の採点）**して実測し、銘柄ごとの差分表をお見せしてから切り替えます。仕組みから予想できる影響は次のとおりです。

| 影響 | 内容 |
|---|---|
| **成長期待点が全体に下がる** | 定性2項目（30点分）が未入力の銘柄は、満点でも70点にしかならず、充足率も70%で「暫定評価」になる。**定性2項目を入れるまで、通常購入候補（成長80以上）は0銘柄になる** |
| 買い点数が配当分だけ上がる | 例: 配当利回り3%で2.5年分なら V が約7%上がり、**買い点数は約＋14点**。無配株は変化なし |
| 売り点数の一部が下がる | 引き上げを廃止するため、下方修正・増資が単独で高い銘柄の売り点数は下がる。その代わり**重大リスク警告が別に出て、再評価対象になる**。株価過熱だけで高かった銘柄も少し下がる |
| 赤字企業の一部が評価可能に | 新興赤字企業のうち、売上予測がある銘柄が「未算定」からPSR評価に変わる |
| 注文候補は減る | 信頼度A/B・充足率80%・重大リスクなしの条件が増えるため |

### 川崎重工の売り点数80点の再検証
- **v4以前の計算**: 売り点数＝max(加重平均, 重大項目×0.8) でした。80点ちょうどは「増資・希薄化」か「下方修正」が100点になったときの値です。
- **可能性が高い原因**: 1:5分割（2026年4月）のあと、決算短信が株数を分割後の基準で書き直したため、株数の増加（約5倍）を希薄化100点と誤判定したと考えられます。
- **確認方法**: PCで `explain 7012` を実行し、「増資・希薄化」の点数と「株数が5.0倍（分割の可能性…）」の表示を確認します。v4の修正で0付近になっていれば確定です。フジクラも同じ方法で確認します。
- **過去の点数**: v4以前の点数は `scores_archive` に残っています。v5の検証では、誤判定があった期間の売り点数を「データ異常」として集計から除外します。

## 4. テスト方法（品質保証の項目ごと）

| 確認項目 | テスト |
|---|---|
| 同じ入力から同じ点数 | 同じDBで2回採点し、全項目が一致すること。点数に現在時刻を使わないこと |
| データ不足が高得点にならない | 項目を1つずつ欠損させて、点数が上がらない（単調性）こと。充足率80%未満は正式評価にならないこと |
| 未算定と0点の区別 | 赤字・データ不足は NULL、実際に割高な場合だけ 0 になること |
| 分割を希薄化と誤判定しない | 1:2、1:5、1:10 の分割（調整係数あり・なし）で、希薄化が0のままになること。実際の増資（+5%）は検出されること |
| 赤字企業にPERを当てない | EPSがマイナスのとき、PERの理論価値を出さないこと |
| 3点数の独立 | 買い点数（株価）だけを変えても、成長期待点が変わらないこと。売り点数が買い点数の単純な反転でないこと |
| 重大リスクが薄められない | 他の6項目が0点でも、重大リスク警告が出て再評価対象になること |
| 事実と予測の区別 | 推計値には「推計」のラベルが付き、公表値と別の欄に保存されること |
| 将来情報を混ぜない | 評価日より後に公表された決算・開示・修正を使わないこと（公表日時で切る）。過去日で採点し直しても結果が同じになること |
| 変換表の固定 | 付表の各点（境界値）で、期待どおりの点数になること |
| v4との比較 | 実データの並行採点で差分を一覧にし、想定外の大きな変化を確認すること |

## 5. 実装手順

1. **v5を別モジュールとして実装する**。v4のコードと過去の点数は残す。
2. **テストを追加する**（第4節の全項目）。
3. **影の採点を行う**。PCで v4 を正式、v5 を参考として並行採点し、差分表（銘柄ごとの3点数・信頼度・警告）を作ってお見せする。
4. **承認後に切り替える**。v5を正式な方式にし、v4は比較用として保存を続ける。
5. **定性2項目を補う**。残り50銘柄の調査で、定性2項目と配当性向も前提案に含める。既存の10銘柄は追加調査する。

**目安**: 実装とテストに1〜2日、影の採点と差分確認に1営業日です。

## 6. 決めていただきたいこと

1. **欠損項目の扱い**: 「0点として加算（保守的）」でよいか。この場合、定性2項目を入れるまで成長期待80点以上は出ません。
2. **定性2項目（市場拡大・競争優位）**: 調査担当が根拠付きで作成し、承認時に確認する運用でよいか。
3. **配当の反映**: 配当の現在価値を加えてよいか（配当株の買い点数が上がります）。
4. **重大リスク**: 売り点数への引き上げを廃止し、別の警告に分ける方式でよいか。
5. **信頼度A〜Dの算定方法**（第1節 D）でよいか。
6. 上記で **v5の実装に進んでよいか**。
