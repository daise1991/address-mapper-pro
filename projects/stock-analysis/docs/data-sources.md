# データ提供元の調査（2026年10月時点）

> 調査環境の制約により、jpx-jquants.com / jpx.co.jp の本文を直接取得できず、多くを検索結果の要約に頼っています。
> 「未確認」と書いた項目は、契約前に公式ページで確認してください。

## 結論

| 用途 | 採用 | 理由 |
|---|---|---|
| 日足OHLCV・調整係数・取引カレンダー・上場一覧・決算短信サマリー | **J-Quants API V2 Light（月1,650円）以上** | JPX公式、商用以外の個人利用向け。日足は16:30頃更新で 18:00 通知に間に合う。Free は12週間遅延のため不可 |
| 有価証券報告書・臨時報告書・有価証券届出書（増資）・XBRL | **EDINET API v2（無料）** | 金融庁公式。APIキー登録のみ |
| 適時開示（業績修正・自社株買い等） | J-Quants **TDnet アドオン（月11,000円, Light以上）** を推奨。費用を抑える場合は EDINET＋決算短信サマリーの予想変化で代替 | TDnet に無料の公式APIは無い |
| 株探・Yahoo!ファイナンス | **自動取得しない** | Yahoo!ファイナンスはスクレイピング禁止と明示。株探はサーバー負荷・運営妨害を禁止事項に含む。画面での目視確認に限る |
| 各社IR | 定性評価・前提の根拠として手動参照 | 形式がばらばらで自動化コストが高い |

## J-Quants API

### V2 への移行
- **認証**: APIキー方式に変わりました。ダッシュボードの「設定 » APIキー」で発行し、`x-api-key` ヘッダーに付けます。
- **V1**: 閉鎖済みです。
- **ベースURL**: `https://api.jquants.com/v2`

### 主なパス

| データ | V1 のパス | V2 のパス |
|---|---|---|
| 日足四本値 | `/v1/prices/daily_quotes` | `/v2/equities/bars/daily`（カラム名が短縮された） |
| 上場銘柄一覧 | `/v1/listed/info` | `/v2/equities/master` |
| 取引カレンダー | `/v1/markets/trading_calendar` | `/v2/markets/calendar` |
| 決算発表予定 | — | `/v2/equities/earnings-calendar` |
| 財務サマリー | `/fins/statements`（後継とみられる。未確認） | `/v2/fins/summary` |

### プランの比較（税込・月額）

| プラン | 月額 | 過去データ | API呼び出し上限（回/分） | 主な追加データ |
|---|---|---|---|---|
| Free | 0円 | 2年 | 5 | 12週間遅延 |
| Light | 1,650円 | 5年 | 60 | 投資部門別、TOPIX |
| Standard | 3,300円 | 10年 | 120 | 指数四本値、信用取引 |
| Premium | 16,500円 | 20年 | 500 | 前後場四本値、配当、財務諸表（BS/PL/CF） |

- **全プラン共通**: 日足、財務サマリー、決算発表予定、取引カレンダー、上場一覧
- **アドオン**: TDnet適時開示（2026/5/18 開始、Light 以上、月11,000円、過去5年分）、分足・ティック

### 更新時刻
- **日足・指数**: 16:30 頃に更新されます。**当日15:30の終値を18:00までに取得するのは、Light 以上なら可能**です。
  アプリでは 16:00 から取得を試み、未配信の間は待機して再試行します。
- **上場一覧**: 翌営業日分が17:30以降に更新されます。

### 本アプリで必要なプラン
- **最低限**: Light で足ります（60銘柄 × 1日数回 ＝ 上限の範囲内）。
- **Premium が必要になる場合**: 配当の明細と、BS/PL/CF の詳細を使うときだけです。
  有利子負債・営業CFの詳細は EDINET の XBRL で補えば Premium は不要です。

## EDINET API v2
- **料金・認証**: 無料です。`Subscription-Key` をクエリで渡します。
- **書類一覧**: `GET https://api.edinet-fsa.go.jp/api/v2/documents.json?date=YYYY-MM-DD&type=2`
- **書類取得**: `GET .../documents/{docID}?type=1|2|5`（1=XBRL ZIP、2=PDF、5=CSV）
- **取得間隔**: 公式の上限は未確認です。実装ではリクエストの間を3秒空けています。

## TDnet
- **無料の公式APIはありません**。閲覧サイトは31日分の PDF 掲載です。
- **法人向け TDnet API**: 有料で、件数に応じた段階料金です。
- **個人向け**: J-Quants の TDnet アドオンが現実的です。

## SBI証券 S株（単元未満株）
- **約定タイミング**: 注文した時刻で決まります（約定は1日3回）。

  | 注文時刻 | 約定 |
  |---|---|
  | 0:00〜7:00 | 当日の前場始値 |
  | 7:00〜10:30 | 当日の後場始値 |
  | 10:30〜13:30 | 当日の終値 |
  | 13:30〜24:00 | 翌営業日の前場始値 |

- **アプリでの前提**: 18:00 の分析を見て当日夜に注文すると、**翌営業日の前場始値で約定**します。
  そのため注文案では、始値が上振れした場合に備えて 3% のバッファを見込んでいます。
- **手数料**: 0円です（インターネットコースで、電子交付に同意していることが条件。2026年時点で条件の変更がないかは未確認）。
