# v5 実装報告（比較検証用・正式切替前）　2026-10-10

## 実装した内容
- **独立実装**: v5 は `backend/stock_analysis/v5/` に、v4 とは別に実装しました。結果は `scores_v5` に保存し、v4（`scores`）は変更しません（テストで確認済み）。毎日の処理では v4 の正式採点のあとに v5 を参考採点し、v5 が失敗しても v4 は止まりません。
- **欠損の扱い**: 取得できた項目だけで採点し、欠損は「未評価」として記録します（0点にしません）。
  - 正式点数: 充足率80%以上、かつ必須項目がすべて評価済みのとき。それ以外は「参考点数」として区別して表示します。
  - 総合の正式評価: 成長・売りが正式、買いが調査前提で算定済み、信頼度A/B、前提が承認済み、のすべてを満たすときだけ。参考点数は正式ランキング・注文候補に使いません。
- **成長期待点**: 過去3〜5年の年平均成長率（40%）と会社予想（60%）を組み合わせ、利益率・ROE・営業CFは過去平均で評価します。変換表は `v5/growth.py` に数値で定義しています。
- **市場拡大・競争優位**: 承認済み評価ルール（`v5/qualitative.py`）で、調査の構成要素からアプリが点数を再計算します。情報源・発表日・理由を保存し、根拠のない要素は未評価にします。最初の10銘柄の調査結果は `assumptions/qualitative_batch1_2026-10.json` です。
- **買い点数**: 標準シナリオで算定します（式と係数200は v4 と同じ、係数150も保存）。
  - **予想配当の加算**: 予想配当の現在価値を加えます。条件は次のとおりです。
    - 二重計上を防ぐため、目標期の配当は加えません。
    - 1期目は会社予想、以降は「EPS×過去3期の平均配当性向（上限70%）」で、増配は年10%を上限にします。
    - 配当データが無い場合は加えません。
  - **保存と表示**: 配当を加える前後の理論価値・買い点数と、弱気シナリオ時の下落率を保存して表示します。
  - **赤字企業**: PERは使いません。PSRは、利益率・資金繰り（2年以上）・増資リスクの根拠がそろったときだけ参考値として出し、正式な買い点数には使いません。根拠がなければ未算定です。
- **売り点数**: 重大リスクで点数を引き上げる処理をやめ、7項目の加重評価だけにしました。RSIだけでは最大40点（売り点数への影響は最大4点）に抑えます。株式分割は、調整係数で補正し、整数倍の増加は除外します。
- **重大リスク警告**（`v5/risk.py`）: 次のどれかで警告を出し、売り点数に関係なく「再評価対象」にして、購入候補から除外します。警告だけで売却を確定はしません。
  - 営業利益予想の15%以上の減額
  - 営業CF赤字かつ自己資本比率20%未満
  - 債務超過
  - 分割補正後の株数の10%以上の増加
  - 増資の開示
- **予測信頼度 A〜D**（`v5/confidence.py`）:
  - 配点: 充足率30・公式情報との整合性25・更新日15・予測幅15・過去の予測誤差15
  - 境界: A≥85、B≥70、C≥50、D<50
  - 強制D: 必須データの欠落、または公式データとの20%超の乖離
  - 過去の予測誤差: 検証データが2件未満のときは「検証期間不足」として配点から外し、85点満点を100点に換算します。0点にはしません。
- **検証の追加**: 売り75点以上と85点以上の比較、成長期待80点以上、業種別（J-Quants の17業種）を追加し、v4 と v5 を切り替えて集計できます。
- **画面**: 「v5比較」タブを追加しました。コマンドは `v5-run`、`compare-v5`、`import-qualitative` です。

## 追加（2026-10-10・push 承認時の条件）
- 正式な採点方式は v4 のまま。v5 は比較検証用で、自動通知・売買候補・注文計画に使わない。毎日の自動処理での v5 参考採点も既定で停止（`STOCK_V5_SHADOW=1` のときだけ実行）。比較は `compare-v5` で行う。
- 想定PER（方針B）: 各月末の調整後株価 ÷ その時点で公表済みの直近本決算EPS（分割補正）から過去5年の実績PERを求め、標準=中央値、弱気=25%点、強気=75%点とする。赤字の月は除外。調査PERでの買い点数も比較用に保存。
- PERの異常の目印（付いた銘柄は正式評価にしない・要確認）: 有効36か月未満／赤字の期間あり／中央値が5倍未満または60倍超／75%点÷25%点が2倍超／営業利益率が5年前の2倍超・半分未満または赤字黒字の転換／売上の年平均成長率25%超／調査の標準PERと±50%超の乖離。
- 定性評価（2026-10-10 改定、詳細は [qualitative-v2-spec.md](qualitative-v2-spec.md)）: `primary_verified` の一括管理を廃止し、`company_verified`（競争優位の会社情報）・`market_verified`（市場成長率の出典と対応関係）・`calculation_verified`（アプリの検査に合格、自動判定）の3つに分けた。市場拡大は市場検証＋計算検証、競争優位は会社検証＋計算検証がそろった項目だけ正式点数に使う。そろわない項目は参考点数にだけ含め、正式点数では未評価（0点にしない）。規則外の点数は正式点数ではエラー（自動補正しない）。保存先は v5 専用の `qualitative_v5` 表で、v4 と調査前提（3シナリオ）には触れない。
