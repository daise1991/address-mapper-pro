## 2. 検証で分かったこと

### (1) 標準シナリオでは、10銘柄中9銘柄が買い0点
- **全体の傾向**: 10銘柄とも、現在の株価が標準シナリオの理論価値を上回っています。ANYCOLOR だけ買い点数38点で、残り9銘柄は0点です。
- **原因**: 想定PER（標準10〜22倍）が、市場が織り込んでいる水準（損益分岐PER 15.6〜71.6倍）より大幅に低いためです。
  - 調査担当には「ピーク利益を延長しない」「景気循環株は正常化利益も評価する」と指示しており、その結果、EPS もPERも保守的になっています。
- **解釈は2通り考えられます**（どちらが正しいかは、検証データが貯まるまで判断できません）。
  - **A. 割高の正しい警告**: 半導体・電線株は、AI関連の期待で正常化利益の数倍の水準まで買われています。
  - **B. 想定PERが低すぎる**: 成長が続く企業に低PERを当てているため、理論価値が過小になっています。
- **強気シナリオなら買い圏に入る銘柄**: ANYCOLOR（100点）、ミネベアミツミ（79点）、川崎重工（75点）です。

### (2) 景気循環株で「標準EPSが正常化EPSを大きく上回る」銘柄
- **該当**: 住友電工（2.2倍）、古河電工（1.9倍）、三井海洋開発（1.8倍）、川崎重工（2.4倍）、アドバンテスト（1.9倍）。
- **調査担当の根拠**: 構造的な成長（AIデータセンター、防衛、FPSO）です。それでも、最高益を更新中の今期の会社予想よりは低く設定しています。
- **アプリでの扱い**: 自動検証で「ピーク延長でないか根拠の確認が必要」と警告します。**承認時に、この根拠が妥当かを判断してください。**

### (3) データの信頼性
- **一次資料が読めていない**: 調査環境の制約で、決算短信・IR資料の原本を直接開けませんでした。すべて検索結果の抜粋に基づいており、**信頼度は「中」7銘柄、「低」2銘柄（古河電工、三井海洋開発）** です。
- **PCで公式データと自動照合**: アプリに取り込むと、あなたのPCの J-Quants 公式データ（会社予想EPS、過去の純利益）と自動で照合し、5%を超える差を「要確認」と表示します。
- **調査中に見つかった株式分割**:
  - 川崎重工（1:5、2026年4月）
  - 住友電工（1:4、2026年7月）
  - 古河電工（1:10、2026年7月）
  - 三洋貿易（1:2、2026年7月）

  株価は J-Quants の調整後終値で、正常化EPSは「純利益÷現在の株数」で計算するため、分割の影響は受けません。
- **増資（希薄化）**: 日本電子材料（2026年3月、約14%）、三井海洋開発（2022年以降、約20%）。

## 3. 60銘柄への展開と自動化の方式（承認をお願いします）

| 段階 | 内容 | 利用者の作業 |
|---|---|---|
| 初回作成 | Claude が公開資料を調べ、10銘柄単位で3シナリオの前提案を作成する（本書と同じ形式） | 初回の方式と各回の内容を確認する |
| 取込と検証 | `import-research` で暫定評価として登録する。自動検算（大小関係・ピーク延長・成長率・PER）と J-Quants との照合を行う | 結果を確認する |
| 承認 | 画面の「検証済みにする」ボタン、または `approve` コマンドで、まとめて承認する | 1回だけ |
| 毎日の自動更新（ルールR1） | 2029年EPSを、基準EPS（会社予想EPS、景気循環株は正常化EPS）の変化率の**半分**だけ自動で増減させ、当日終値で理論価値と点数を再計算する | なし |
| 再承認が必要になる条件 | ①基準EPSが登録時から±15%以上変化 ②承認後に下方修正の開示 ③計算方式の変更 ／ 当日の株価データに異常がある場合は、その日の注文候補から外す | 通知が来たときだけ確認する |

**検討をお願いしたい改善案（未採用）**: 想定PERを、調査担当の判断ではなく **J-Quants の過去5年の期末PERの中央値**から自動で決めるルールです。PERの決め方を銘柄間で揃えられ、手作業も減ります。採用する場合は、計算方式のバージョンを上げて導入します。

## 4. 注文候補の条件（実装済み）

点数の条件（成長期待80以上・買い75以上・売り40以下）に加えて、次をすべて満たす銘柄だけを注文案に載せます。満たさない銘柄は、理由を付けて「見送り」と表示します。

- 評価前提が **検証済み**
- 信頼度が「高」または「中」
- 直近90日に下方修正がない
- 財務悪化の評価が60未満、増資・希薄化の評価が50未満
- 当日の株価データに異常がない
- 終値が理論価値以下
- 資金管理: 月3万円の予算、買付余力、1銘柄あたりの上限、購入許容上限価格（終値＋3%）

注文案の表示と実際の発注は分けています。自動発注は行いません。
