# 新興株の定期選別（2026-10-10）

監視中の新興株20銘柄は固定の一覧である。これとは別に、グロース市場の全銘柄を毎月1回調べ、条件を満たす銘柄を「追加候補」、条件を外れた監視中の銘柄を「外す候補」として報告する。

- 銘柄の追加・削除は経営者の承認後に手で行う。選別は監視銘柄（`securities`）も v4 の点数も変えない。
- 実行：`run-all` の待ち受けが毎月1日の9時以降に1回実行し、通知を出す。失敗したら1時間後にやり直す。
- 手動実行：`python -m stock_analysis screen-emerging [--date YYYY-MM-DD] [--out ファイル]`。報告は `data/emerging_screen_<日付>.md`。
- 所要時間：約8分（全銘柄の決算を1社ずつ取得するため）。

## 条件（設定 `emerging_screen` で変更できる）

| 項目 | 初期値 |
|---|---|
| 市場 | 市場名に「グロース」を含む |
| 売上の伸び（直近の本決算と前年の本決算） | 20%以上 |
| 時価総額 | 100億円以上 |
| 売買代金（直近20営業日の平均） | 1億円以上 |
| 上場からの期間 | 1年以上 |
| 株数の増加（自己株式を除く、株式分割は補正） | 10%以下 |

- 株式分割は株価の調整係数から倍率を求めて補正する。分割を確認できない場合は「確認不可」として条件外にする。
- 取得できなかった値は0点にせず「取得不可」として報告に載せる。
