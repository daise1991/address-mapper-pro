## 6. 60銘柄の取得に必要な実装

J-Quants・EDINET 向けの取得部分は、すでに作ってあります（営業日判定、再試行、重複防止、異常値・欠損の記録、取得元・取得日時の記録）。加えて必要なのは次の作業です。

1. **項目名・パスの照合**：J-Quants V2 の実データでカラム名とパスを確かめ、テストで固定する（契約後）。
2. **一括取得への変更**：日付を指定すれば全銘柄を1回で取れるので、銘柄ごとの取得から切り替える（Lightの上限は60回/分）。
3. **比較対象の取得**：TOPIX（`/indices/bars/daily/topix`）と 2644 の日足を取得し、検証の比較基準にする。
4. **会社予想の修正の検出**：J-Quants の決算情報に含まれる「業績予想の修正」「配当予想の修正」の書類種別を使う（V2 での名称は未確認）。
5. **EDINETからの取り込み**：増資（有価証券届出書・臨時報告書）と自社株買い（自己株券買付状況報告書）を取り込む。有利子負債は実装済み。
6. **取得できないものの明示**：大型受注・自社株買い決議の速報は、TDnetアドオンなしでは取れません。画面に「対象外」と表示します。

```
[J-Quants Light API] ──┐ 日足・TOPIX・決算サマリー・会社予想修正（16:30頃〜）
[EDINET API（無料）] ──┤ 有報・増資・自己株・有利子負債

                       ▼
   iPhone（ホーム画面に追加したWebアプリ、iOS 16.4以降）／ PC ブラウザ
```
